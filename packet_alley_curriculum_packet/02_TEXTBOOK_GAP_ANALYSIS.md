# Curriculum gap analysis against the textbook

**Primary source:** Olivier Bonaventure, *Computer Networking: Principles, Protocols and Practice*, 3rd edition, open repository: https://github.com/cnp3/ebook (CC BY-SA 3.0 at repo level, check per-file notices). This evaluation compares the existing Packet Alley topics with the book's principles, Ethernet, datagram forwarding, TCP, reliable transfer and resource-sharing sections. This is a curriculum comparison, not an assertion that every textbook topic belongs in one short game.

| Priority | Missing or misleading objective | Existing game evidence | Proposed map-native exercise | Book reference |
|---|---|---|---|---|
| P0 | Distinguish link-layer MAC from network-layer IP | `address` introduces IP as the basis of switching | Inspect two nested headers; predict MAC port lookup with source learning | [Datalink layer technologies](https://beta.computer-networking.info/syllabus/default/protocols/lan.html) |
| P0 | Explain unknown-unicast flooding and MAC learning | One quiz asks it, without a pre-task observation | Observe learning, select the source MAC that updated the switch table, then send unseen destination | Same |
| P0 | Reason through loops and spanning-tree port roles | `loop` says “block the spare” | Find a spanning forwarding tree across several connected switches, preserving reachability | [LAN exercises](https://beta.computer-networking.info/syllabus/default/exercises/lan.html) |
| P0 | Contrast GBN teaching model with real TCP's reliable byte-stream and congestion control | Transfer stories imply GBN is TCP | Explicit model badge, side-by-side TCP segment/header traces, ACK/window discussion | [Reliable transfer principles](https://beta.computer-networking.info/syllabus/default/principles/reliability.html), [TCP](https://beta.computer-networking.info/syllabus/default/protocols/tcp.html) |
| P0 | Replace guessable choices with evidential predictions | Most early tasks are 2–3 options, quizzes index zero | Preflight evidence + predicted path + one scored commit per deterministic case | [Book exercises](https://beta.computer-networking.info/syllabus/default/exercises/lan.html) |
| P1 | Apply prefix matching, including overlapping entries | Routes generally specify target prefix in question | Inspect candidate prefixes and decide longest match before editing next hops | [Building a network](https://beta.computer-networking.info/syllabus/default/principles/network.html) |
| P1 | Diagnose forward **and return** paths | Some level goals are ping replies, but tasks only discuss outbound route | Trace echo request and response with independent route cards | Same |
| P1 | Distinguish direct delivery, next hop, ARP, and end-to-end transport | ARP appears in Handshakes | Persistent layered packet inspector and explicit local-neighbor mini-lesson | [Ethernet](https://beta.computer-networking.info/syllabus/default/protocols/lan.html), [TCP](https://beta.computer-networking.info/syllabus/default/protocols/tcp.html) |
| P1 | Understand TCP four-tuple and ports | Handshake quiz focuses flags and `y+1` | Endpoint sockets on devices; track source/destination ports and ACK derivation | [TCP header](https://beta.computer-networking.info/syllabus/default/protocols/tcp.html) |
| P1 | Predict results under failures without iterating arbitrary options | Deterministic Run reveals outcomes and allows retry | One graded case, derived practice variant after error, evidence-first diagnostic trace | [Network paths/black holes](https://beta.computer-networking.info/syllabus/default/principles/network.html) |
| P1 | Separate finite-buffer loss from intent to attack | Watch-only chapter calls honest traffic a denial of service | Queue capacity visualization, fair sharing/legitimate overload question | [Sharing resources](https://beta.computer-networking.info/syllabus/default/principles/sharing.html) |
| P2 | Repair after a link fails while retaining redundancy | Existing redundant links are simply blocked | Extension: remove one active link and predict which inactive port must resume forwarding | [LAN exercise 2](https://beta.computer-networking.info/syllabus/default/exercises/lan.html) |
| P2 | Selective-repeat vs GBN comparison; retransmission timers | GBN only | Optional after final mission: compare traces on same injected loss | [Reliable transfer](https://beta.computer-networking.info/syllabus/default/principles/reliability.html) |
| P2 | Fairness/queuing and rate-capacity reasoning | `flood` only watch and multiple choice | Read queue length versus service rate; inspect effects of varying legitimate arrival patterns | [Sharing resources](https://beta.computer-networking.info/syllabus/default/principles/sharing.html) |

**Scope boundary:** Do not add DNS, TLS, BGP, wireless radio, IPv6 addressing, or active attack construction merely to fill the textbook table of contents. Those would require independent instructor approval and a different sized game. Where packet prefixes represent IPv4, label this explicitly; the textbook's third edition also covers IPv6.

**Learning-outcome rubric (per zone):** (1) can recognize the relevant visible state; (2) can predict behavior on an unseen case; (3) can repair or configure by direct map interaction; (4) can justify the decision using device/packet evidence; (5) can distinguish simplified simulator behavior from actual network protocol rules. Only credit all outcomes when the evidence is observed, not when a menu happens to produce a green animation.
